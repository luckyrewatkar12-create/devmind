## ✨ Features

| Feature | Description |
|---|---|
| 📊 **Dashboard** | Learning roadmaps, XP/level system, streak tracker, activity feed |
| 🔍 **AI Code Explainer** | Paste any code → instant step-by-step plain-English breakdown |
| ⚡ **Adaptive Quiz Engine** | 6 topics × 3 difficulty levels with AI-generated questions |
| 🐛 **AI Debugger** | Paste buggy code → get root cause diagnosis + exact fixes |
| 💬 **AI Tutor Chat** | Conversational tutor for any programming concept |

---

## 🎯 Problem Statement

> *Build an AI-powered solution that helps people learn faster, work smarter, or become more productive while building or understanding technology.*

**DevMind** directly addresses this by combining:
- **Interactive learning** with adaptive quizzes and instant feedback
- **Developer productivity** with AI-powered debugging and code explanation
- **Gamification** (XP, levels, streaks) to keep learners motivated

---

## 🛠️ Tech Stack

- **Frontend:** Pure HTML5, CSS3, Vanilla JavaScript
- **AI Logic:** Rule-based NLP engine with contextual knowledge base
- **Deployment:** Vercel (CDN, global edge)
- **No dependencies** — runs 100% offline, zero build step
