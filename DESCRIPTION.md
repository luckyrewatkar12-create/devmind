# DevMind — AI Learning Accelerator
## Hackathon 2025 · Built by Lucky Rewatkar

### 🌐 Live Demo
https://bob-files-cq6f4w33z-xmen4.vercel.app

### 📌 Problem Statement
Build an AI-powered solution that helps people learn faster, work smarter,
or become more productive while building or understanding technology.

### 💡 Solution
DevMind is a single-page AI-powered platform with 5 tools:
1. 🔍 AI Code Explainer  — explains any code in plain English
2. ⚡ AI Quiz Engine     — generates fresh quizzes on 9 topics
3. 🐛 AI Debugger       — diagnoses bugs + writes the fix
4. 💬 AI Tutor Chat     — answers any programming question
5. 📊 Learning Dashboard — XP, levels, streaks, roadmaps

### 🤖 AI Model
Google Gemini 1.5 Flash (via REST API, browser-side, no backend)

### 🛠️ Stack
HTML5 · CSS3 · Vanilla JavaScript · Gemini API · Vercel
